# Doubly Linked List - C Lab Exercise

## Overview
A C-based laboratory exercise for implementing a **Doubly Linked List** ADT. Students complete the function stubs in `list.c` to implement list operations.

## Important
**Do NOT modify `list.c`** — it contains student exercises. The comment at the top of `list.c` enforces this.

## Files
- `list.h` — Header with struct declarations and function prototypes
- `list.c` — Student implementation file (do not modify)
- `main.c` — Example usage with Pelicula (Movie) structs
- `test.c` — Automated unit tests
- `test.sh` — Test runner script (compiles and runs tests, tracks progress via git)

## How to Run
- **Main program**: Compiled and run via the "Run program" workflow (`gcc main.c list.c -o main_prog && ./main_prog`)
- **Tests**: Run `bash test.sh` in the shell

## Tech Stack
- Language: C
- Compiler: gcc
- Environment: NixOS (replit.nix)
